# Проблемные места

* Использование единой базы данных для всех сервисов
* Отсутствие ролевой модели (RBAC/ABAC)
* Присутствие сложной логики в DWH
* Устаревшая шина данных
* Устаревшая база данных
* Сложный доступ к данным в текущей архитектуре
